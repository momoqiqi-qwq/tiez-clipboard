# 2026-09-12

## 数字快速粘贴（修饰键 + 1-9/0）语义改造

需求：`Alt+1~9` 直接粘贴列表中最近的前几项内容。原实现只支持「固定(pinned)项」，
且默认关闭，与需求不符。

设计决策（经用户确认）：
- 槽位 = **列表显示顺序**（固定项在最前按 pinned_order，其后按时间倒序），
  数字 N 即列表第 N 项。无固定项时 Alt+1~9 自然就是最近 9 条。
- 默认修饰键改为 **Alt**（仅 Windows，新装生效）。

改动文件：
- `src-tauri/src/services/clipboard_ops.rs` — `paste_history_item_by_index`
  删除 `if !item.is_pinned { return Ok(false) }` 限制，补文档注释说明槽位语义。
- `src/App.tsx` — `buildQuickPasteHintsById`：`items.filter(is_pinned).slice(10)`
  → `items.slice(10)`，槽位与后端索引严格对齐。
- `src/features/clipboard/components/ClipboardItem.tsx` — 角标渲染去掉 `item.is_pinned` 条件。
- `src-tauri/src/database.rs` — 默认值 `disabled` → `alt`，用 `#[cfg]` 分平台
  （macOS 无键盘钩子，保持 disabled，避免角标是摆设）。
- `src/locales.ts` — zh / en / zh-TW 三处 `quick_paste_modifier_hint` 文案改为
  「列表中第 1-10 项（固定项在最前，其后是最近记录）」。

验证：`tsc --noEmit` 通过；`cargo build` 通过（仅遗留 `pull_remote_settings_snapshot`
未使用的旧 warning）。

注意：已存在的数据库行 `app.quick_paste_modifier` 是 `disabled`，
`INSERT OR IGNORE` 不会覆盖，需到「设置 → 剪贴板设置」手动选 Alt 才生效。

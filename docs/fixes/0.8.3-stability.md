# 0.8.3 窗口恢复与标签操作修复

本次为补丁升级，保留工作区已有修改。标签创建功能原已存在，本次修复其输入与异步更新问题。

## 修复内容

- 延迟失焦隐藏操作绑定窗口显示代次。重新打开、重新获得焦点或主动关闭后，旧任务失效；最终判断在 UI 线程执行，并重新检查贴边、置顶、拖拽和鼠标状态。
- 托盘菜单、托盘点击及再次启动统一使用窗口恢复入口，恢复贴边隐藏和最小化状态。Esc 使用幂等隐藏，防止重复按键重新打开窗口。
- 主窗口获得焦点时，原生导航钩子将按键交还 WebView；前端全局导航及标签输入均保护输入法组合态，避免候选确认触发粘贴、隐藏或误创建标签。
- 窗口初始隐藏，仅恢复上次的位置和尺寸。React 挂载后通知显示；页面重载重新等待就绪。通知最多尝试 3 次，5 秒超时后允许显示静态恢复界面，保持手动重载入口可用。
- React 渲染异常显示不透明恢复页；模块加载失败显示静态启动兜底。重载不清除已保存记录和设置。
- Win32 钩子或托盘创建失败改为记录错误并降级，避免 `expect()` 在 release 的 `panic=abort` 下直接终止进程。消息循环正确处理 `GetMessageW == -1`。
- panic 日志只记录线程和源码位置，省略可能含剪贴板内容的异常载荷；日志锁内发生 panic 时也能写入诊断。
- 标签管理丢弃过期异步响应、清理晚到监听；切换标签清除旧勾选项与删除确认，防止批量操作影响当前看不到的记录。

## 标签使用

在记录卡片的标签编辑器输入名称添加标签；也可进入标签管理，在搜索框输入新名称后按 Enter 或点击「+」。中文输入法选词时的 Enter 不会提交创建。
